# 素材

**對象：** 為第一個廣告系列準備廣告的廣告主和設計師。

素材就是玩家看到的廣告。AdWave 會讓你的素材互相比拼，把預算轉向表現最好的，並淘汰開始失效的。你提供的素材越多樣，它就越快找出致勝素材。

## 1. 需要多少素材 {#_1-how-many-creatives-you-need}

上線前準備 **8–10 組素材**。

- **學得更快：** 素材之間差異越明顯，AdWave 學得越快。
- **CPA 更低：** 選擇越多，越有機會找到更便宜的轉化。
- **不易疲勞：** 某一組效果轉差時，可以換上其他組。

::: tip 保持新鮮感
當某個素材的 CTR 或轉化開始下跌時，**每 2 週新增 2–3 組**。
:::

## 2. 怎樣才算一組素材 {#_2-what-makes-a-creative-set}

一組素材就是廣告的一個版本，最少在以下其中一方面與其他組不同。先由你網站上轉化表現已經不錯的優惠和文案入手。

| 維度 | 例子 |
| --- | --- |
| **優惠** | 首存 100% 獎賞、50 次免費旋轉、2% 回贈、VIP 計劃、限時活動 |
| **主題** | 老虎機、Crash、真人娛樂場、體育博彩、撲克 |
| **文案** | 獎池金額、快速提款、安全持牌、新玩家專享、倒數 |
| **視覺** | 真人荷官或模特兒、遊戲畫面、大獎畫面、體育明星 |
| **本地化** | 語言、本地遊戲、本地付款方式、本地節日 |

**每次只測試一個變數。** 先找出最好的優惠，再為這個優惠測試不同切入點，最後測試視覺。

## 3. 各廣告格式的規格 {#_3-specs-by-ad-format}

| 格式 | 需要提供 | 規格 |
| --- | --- | --- |
| **Pop** | 落地頁 URL | 無需圖片，Pop 會直接打開你的落地頁。每個優惠一個 URL，使用對應語言 |
| **Push** | 品牌 Logo + 圖片 + 標題 + 描述 | Logo：JPG/PNG，192×192，≤ 200 KB。圖片：JPG/PNG，360×240，≤ 720 KB。標題 ≤ 30 個字元，描述 ≤ 40 個字元（表情符號不計入字數） |
| **Display** | 橫幅圖片 | GIF/JPG/PNG，≤ 500 KB。**先由** 300×250、300×100、320×50 開始。AdWave 亦支援 728×90、468×60 和 160×600 |
| **Native** | 圖片 + 標題 + 描述 | JPG/PNG，≤ 500 KB。尺寸：300×250 |

<!-- Display sizes verified in AdWave on 2026-09-28. TODO (Product): verify Push and Native accepted sizes the same way. -->

::: tip Pop 和 Display 建議用動態素材
動態素材（Display 用 GIF）通常能帶來更多點擊和轉化。小尺寸橫幅請重新排版，不要把大圖直接縮小。
:::

每個素材都應附上各市場要求的法律聲明，例如 **18+**、「負責任博彩」（Play responsibly）和「受條款及細則約束」（T&Cs apply）。

## 4. 第一輪例子 {#_4-example-first-round}

以馬來西亞市場為例，準備 2 個優惠，涵蓋 3 種語言（英文 / 中文 / 馬來文）：

| 格式 | 測試內容 | 組數 |
| --- | --- | --- |
| **Pop** | 2 個優惠 × 2 種視覺（真人荷官、遊戲畫面） | 4 |
| **Display** | 2 個優惠，各做 300×250、300×100 和 320×50 三個尺寸 | 2 |
| **Push** | 2 種文案切入點（倒數、大獎） | 2 |
| **合共** | | **8 組，約 28 個檔案** |

想看各格式的效果預覽，參見 [素材要求與範例](/hk/adwave/creative-requirements)。

## 5. 上載和管理素材 {#_5-upload-and-manage-creatives}

你可以在[建立廣告系列](./create-campaign#_6-creative)時加入素材，亦可以隨時在左邊選單的 **Creative** 上載和查看素材。

![Creatives 列表，顯示每個素材的格式、尺寸、語言、使用情況和成效](/img/handbook/creatives-list.png)

Pop 素材按落地頁 URL 列出。用篩選器（**All Formats**、**All Sizes**、**All Usage**、**All Language**）尋找素材，再按 **Spend** 或 **CTR** 排序，看看哪些素材有效。

::: tip 為每個素材設定語言
標示為 **Unspecified** 的素材很難按市場比較。點擊 **Language** 欄中的鉛筆圖示即可設定。
:::
