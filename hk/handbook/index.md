# 由這裡開始：上線你的第一個廣告系列

**對象：** 首次在 RevoSurge 投放的自助廣告主，包括企業東主、營銷人員和媒體採購。不需要程序化廣告經驗。

讀完這本手冊，你就會有一個已充值的帳戶、一個能記錄轉化的產品，以及一個在 **AdWave**（RevoSurge 的廣告投放工具）上線的廣告系列。

## 1. 運作方式 {#_1-how-it-works}

RevoSurge 會在大量網站和 App 上向玩家展示你的廣告，並從你回傳的轉化（註冊、充值）中學習，再找出更多相似的人。追蹤做得越好，廣告系列的成效就越好。

先填寫下面的[上線準備表](#_2-fill-in-your-launch-worksheet)（約 30 分鐘），再按次序完成以下七個步驟。完成步驟 1–5 即可上線，步驟 6–7 在上線後進行。

| 步驟 | 做甚麼 | 由誰負責 | 所需時間 |
| --- | --- | --- | --- |
| **1. 帳戶與錢包** | 註冊帳戶，再透過客戶經理為錢包充值 | 你 + 客戶經理 | 10 分鐘 + 到帳時間 |
| **2. 接入追蹤** | 把網站登記為產品，並安裝追蹤 | 你 + 開發者 | 即日至 5 天 |
| **3. 落地頁** | 準備玩家點擊廣告後到達的頁面 | 你 | 1 天 |
| **4. 素材** | 準備 8–10 組素材 | 你或設計師 | 1–2 天 |
| **5. 建立廣告系列** | 在 AdWave 建立並上線廣告系列 | 你 | 20 分鐘 |
| **6. 投放第一週** | 檢查投放和轉化，再決定放量、調整還是停投 | 你 | 每天 10 分鐘 |
| **7. 優化與放量** | 提升成效，把有效的投放做大 | 你 | 每週 |

步驟 2–4 可以同步進行：開發者安裝追蹤期間，你就可以準備落地頁和素材。

AdWave 首頁會顯示你的設定進度。每完成一步，該步驟就會變綠；全部完成後，**Create Campaign** 便會解鎖。

![AdWave 引導清單：Create Product、Setup Web Tracker、S2S Postback 和 Create Campaign](/img/handbook/adwave-onboarding-wizard.png)

::: info 追蹤要多久？
如果玩家在你的網站上註冊，單用 **Web 追蹤器**已經足夠，即日就能上線。如果想按你自己後端記錄的充值來優化，開發者還需要接入 **S2S**，約需 2–5 天。參見 [追蹤概述 → 選擇你的設定方案](/hk/tracking/overview#_2-choose-your-setup)。
:::

## 2. 填寫上線準備表 {#_2-fill-in-your-launch-worksheet}

請在打開 AdWave **之前**填好這張表。設定過程中要作的每個決定，表中都有涵蓋；每個部分都對應 AdWave 的一個步驟，到時你只需把已想好的內容填進去。把表分享給開發者和客戶經理，他們想問的問題，大多都能在表中找到答案。

### 2.1 你的業務 {#_2-1-your-business}

用於：**Product → Create Product**

| 問題 | 如何選擇 |
| --- | --- |
| 產品名稱 | 在報表中一看就認得出的名稱，例如 `BrandX Casino` |
| 主網域 | 要包括 `https://`，例如 `https://brandx.com` |
| 所有落地頁網域 | 列出廣告會導流到的**所有**網域：預落地頁、鏡像網站、轉址網域。未登記的網域無法投放 |
| 每個落地頁的 Funnel Type | **Direct Register** = 玩家直接在此頁面註冊。**Redirect Register** = 此頁面把玩家轉到註冊頁。Download 類型的用法相同，用於 App 安裝 |
| 充值貨幣 | 你的後台用來結算充值的貨幣。如果以加密貨幣結算，就選加密貨幣 |

### 2.2 目標與追蹤 {#_2-2-goal-and-tracking}

用於：**Product → Setup Wizard** 以及廣告系列的 **Target Event**

| 問題 | 你的答案 | 如何選擇 |
| --- | --- | --- |
| 玩家點擊廣告後去哪裡？ | 網頁 / App / 兩者皆有 | App 廣告系列還需要 **AppsFlyer** |
| 目標事件 | Register / FTD / Bet / Landing Page Click | 如果過往轉化紀錄不多，先由 **Register**（註冊）開始。**FTD**（首存）要先能追蹤充值事件。參見 [建立廣告系列 → 目標事件](./create-campaign#_2-objective-and-ad-format) |
| 充值記錄在哪裡？ | 我的後端 / 聯盟平台 / AppsFlyer | 這會決定你用哪種追蹤方式（見下表） |
| 追蹤方式 | | 按下表選擇 |
| 誰負責安裝追蹤？ | 姓名 + 聯絡方式 | 能在你網站加入腳本的開發者 |

| 如果… | 你需要 | 一般所需時間 |
| --- | --- | --- |
| 網頁，目標 = Register | Web 追蹤器 | 即日 |
| 網頁，目標 = FTD，數據在聯盟平台 | Web 追蹤器 + Partner Postback | 即日 |
| 網頁，目標 = FTD，數據在你的後端 | Web 追蹤器 + S2S | 約 2–3 天 |
| App | Web 追蹤器 + AppsFlyer（追蹤充值另需 S2S） | 約 3–5 天 |

詳情參見：[接入追蹤](/hk/tracking/overview)。

### 2.3 投放地區 {#_2-3-where-to-advertise}

用於：廣告系列的 **Target Geo**

| 問題 | 如何選擇 |
| --- | --- |
| 國家或地區 | 每個廣告系列最多 **20** 個。首次測試建議由 1–3 個你熟悉的市場開始 |
| 各市場的廣告語言 | 配合各市場的語言。如果各市場語言不同，就為每種語言準備素材，或每種語言各開一個廣告系列 |

### 2.4 廣告格式、出價與預算 {#_2-4-ad-format-bid-and-budget}

用於：廣告系列的 **Ad Format**、**Bid & Daily Budget** 和 **Schedule**

**每個廣告系列選一種廣告格式：**

| 格式 | 是甚麼 | 適合 | 所需素材 |
| --- | --- | --- | --- |
| **Pop** | 在新視窗打開你的落地頁 | 快速取得轉化量 | 無，只需落地頁 URL |
| **Push** | 推送通知樣式的廣告 | 擴大觸及、喚回用戶 | Logo、圖片、標題、描述 |
| **Display** | 固定在頁面某個位置的橫幅 | 提升曝光 | 橫幅圖片 |
| **Native** | 外觀與網站內容相近的廣告 | 點擊率較高 | 圖片、標題、描述 |

**出價與預算：**

| 問題 | 如何選擇 |
| --- | --- |
| 出價策略 | 選擇 **oCPM**（標有 *Suggested*）。你設定每個目標事件願意付的成本，AdWave 就會去找最有可能轉化的流量 |
| 出價（美元） | 使用 oCPM 時，出價就是你願意為每個目標事件付的成本，即目標 CPA。可與 AdWave 顯示的 **Suggested Bid** 比較 |
| 日預算（美元） | oCPM：約為出價的 **100 倍**，最少 **50 倍**。例如出價 $2.50，日預算約需 $250，不少於 $125。CPM：最少為出價的 **20 倍** |
| 測試總預算（美元） | 日預算 × 測試天數，也就是你要請客戶經理充值的金額 |
| 開始日期 | 即時開始，或選擇未來某一天 |
| 結束日期 / 週期 | 7、14、30、60 或 90 天。首次測試選 **14 天**，就有足夠數據判斷成效 |

### 2.5 素材 {#_2-5-creatives}

用於：廣告系列的 **Creative** 部分

| 格式 | 素材 | 規格 |
| --- | --- | --- |
| **Pop** | 落地頁 URL | 每個優惠一個 URL，無需圖片 |
| **Push** | 品牌 Logo | JPG/PNG，192×192，≤ 200 KB |
| | 圖片 | JPG/PNG，360×240，≤ 720 KB |
| | 標題 / 描述 | ≤ 30 個字元 / ≤ 40 個字元 |
| **Display** | 橫幅 | GIF/JPG/PNG，≤ 500 KB。先由 300×250 · 300×100 · 320×50 開始（AdWave 亦支援 728×90 · 468×60 · 160×600） |
| **Native** | 圖片 + 標題 + 描述 | JPG/PNG，≤ 500 KB，300×250 |

上載前請確認：

- ✅ 已準備 **8–10 組素材**，優惠、視覺和文案各有不同，讓 AdWave 找出效果最好的一組
- ✅ 每個素材都使用對應市場的語言
- ✅ 廣告中的優惠（例如「首存 100% 獎賞」）與落地頁一致
- ✅ 檔案符合上表的大小和尺寸限制

想了解甚麼是素材組，以及查看例子和完整規格，參見 [素材](./creatives)。

### 2.6 落地頁 {#_2-6-landing-page}

用於：廣告系列的 **Destination URL**

檢查你的頁面：

- ✅ 在流動網絡下 2 秒內載入完成
- ✅ 展示與廣告相同的優惠和語言
- ✅ 只有一個清晰的操作（註冊或充值），無需捲動就能看到
- ✅ 註冊表格只收集必要資料

參見 [落地頁與轉化路徑](./landing-page)。

### 2.7 上線前檢查清單 {#_2-7-ready-to-launch-checklist}

- ✅ 錢包已充入全部測試預算（透過客戶經理）
- ✅ 產品在 **Manage Product** 中顯示為 **Active**
- ✅ 目標事件已開始追蹤（可在產品的 **Event Stream** 中看到）
- ✅ 每個落地網域都已在該產品下登記
- ✅ 地區、語言和素材互相配合
- ✅ 出價、日預算和排期已確定
- ✅ 第一週每天都有人查看成效

全部剔好？前往 [建立廣告系列](./create-campaign)。

## 4. 尋求協助 {#_4-get-help}

- **追蹤設定卡住了？** 到 **Product → Setup Wizard** 查看 **Event Stream**，看看網站正在發送甚麼；亦可參見 [Web 追蹤器 → 疑難排查](/hk/tracking/web-tracker/install#troubleshooting)。
- **仍未解決？** 聯絡你的客戶經理，並附上填好的[上線準備表](#_2-fill-in-your-launch-worksheet)。他們想問的問題，表中大多已有答案。
