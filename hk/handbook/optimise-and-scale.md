# 優化與放量

**對象：** 已有最少一週廣告系列數據的廣告主和媒體採購。

廣告系列投放約一週後，你就有足夠數據去改進它。先優化，再為有效的部分放量。

## 1. 甚麼時候可以放量 {#_1-when-a-campaign-is-ready-to-scale}

以下條件全部符合時，就可以放量：

- ✅ 已投放最少 **7 天**
- ✅ **Cohort** 檢視中的 CPA 等於或低於目標 <!-- TODO (Product): same day-7 cohort maturity question as first-week.md -->
- ✅ 每天都能用掉大部分日預算
- ✅ 最少有一組素材明顯勝過其他組

如果 CPA 高於目標，先優化，再放量。

## 2. 優化 {#_2-optimise}

按以下次序逐項處理。每次只改一處，等 2–3 天後再檢查。

| 調整項目 | 怎樣做 |
| --- | --- |
| **素材** | 暫停最弱的幾組。以表現最好的一組為基礎，新增 2–3 組：優惠不變，換上新的視覺或文案 |
| **優惠** | 如果每個素材的 CPA 都很高，問題可能出在優惠上。試試不同的獎賞或推廣活動 |
| **落地頁** | 如果 CTR 不錯但註冊少，試試另一款預落地頁範本，或縮短表格 |
| **地區** | 把 CPA 差異很大的地區分拆成獨立的廣告系列，讓每個地區都能各自出價 |
| **出價** | 如果 CPA 遠低於目標但量不多，把出價提高 10–20% |

## 3. 放量 {#_3-scale}

- **逐步提高日預算**，每 2–3 天提高約 20–30%。預算一下子加太多，可能會令學習重新開始。
- **日預算保持在出價的約 100 倍。** 提高出價時，預算亦要一併提高。
- **加入新地區時，請開新的廣告系列**，不要加到已經見效的廣告系列中，這樣才能比較成效。
- **用同一個優惠試第二種廣告格式。** 不同格式能觸及不同的玩家。
- **預先為錢包充值，別讓花費追上餘額。** 提高預算之前，先請客戶經理充值。

## 4. 轉向更深的目標 {#_4-move-to-a-deeper-goal}

Register 廣告系列穩定後，再轉向更接近收入的目標：

1. 確認充值已透過 **S2S** 或 **Partner Postback** 追蹤（[接入追蹤](/hk/tracking/overview#_2-2-which-system-holds-your-conversion-data)）。
2. 新建一個以 **FTD** 為目標事件的廣告系列。
3. 用 **受眾（Audience）** 向已註冊但未充值的玩家再行銷。參見 [受眾 → 受眾細分](/hk/audience/segments)。
