# 廣告系列設定

**對象：** 在 AdWave 投放廣告的 UA 經理、廣告系列營運與增長團隊。

廣告系列設定是一個單頁、逐步進行的流程，帶你在同一處完成從建立產品到上線投放（含素材）的全過程。

## 前提條件 {#prerequisites}

廣告系列建立**受數據配置限制**。在 AdWave 引導頁（**接入你的數據**）上，*建立廣告系列* 會一直鎖定，直到你完成步驟 1–3。開始前請確保：

- **已建立產品。** 建立**產品**（你要推廣的應用或網站），並填寫其網域、追蹤器 ID 與充值匯率。
- **Web 追蹤器已啟用。** 在 Web 追蹤器收到首個事件之前，產品處於 **Inactive（未啟用）** 狀態；只有**已啟用**的產品才能在廣告系列流程中選擇。參見 [安裝 Web 追蹤器](/hk/tracking/web-tracker/install)。
- **轉化事件已追蹤。** 你用於優化的目標事件（如 Register、Deposit）必須已透過追蹤流入。參見 [追蹤 → 概述](/hk/tracking/overview)。
- **錢包已充值。** 你的**錢包**餘額充足。參見 [充值與錢包](/hk/growth/funding-wallet)。
- **素材已就緒。** 素材已按規格準備好。參見 [素材要求與範例](/hk/adwave/creative-requirements)。

> **提示：** 你可在**管理產品**中查看產品狀態——**Tracker Status（追蹤器狀態）** 欄顯示 Active / Inactive，*Data Setup（數據配置）* 顯示有多少事件處於啟用狀態。

## 1) 產品 {#_1-product}

選擇你要推廣的**產品**。每張卡片顯示產品名稱及其 URL。

> **注意：** 「未啟用的產品需先啟用才能投入使用。」 若所需產品尚未啟用，請先啟用，再返回本流程。

## 2) 目標與廣告格式 {#_2-objective-ad-format}

**廣告系列名稱**

輸入用於報表的可讀名稱。AdWave 建議一套命名格式以保持廣告系列一致：

> 建議格式：**地區 + 促銷 + 廣告格式 + 開始日期**——例如 `IN_Register_Display_20260126`。

**目標事件**

選擇本廣告系列要優化的轉化事件。該事件用於衡量轉化並計算廣告系列的 **CPA**。請選擇其一：

- **Register**
- **FTD(First-Time Deposit)**
- **Bet**
- **LP Click**

**廣告格式**

選擇一種格式。每種格式的素材要求不同（見 [步驟 6](#_6-creative)），建議出價也不同：

- **Pop** — 以覆蓋層或新視窗形式出現的廣告。極為吸睛；適合促銷與以轉化為目標的廣告系列。
- **Push** — 直接推送到用戶裝置的通知式廣告。適合再互動與持續觸達用戶。
- **Display** — 放置在固定位置（如側邊欄或頁首）的橫幅式廣告。適合強曝光與廣泛的品牌認知。
- **Native** — 無縫融入內容資訊流的廣告。干擾更小、更具吸引力；適合追求更高點擊率。

![步驟 2——廣告系列名稱、目標事件(Register / FTD / Bet / LP Click)與廣告格式](/img/onboarding/campaign-step2-objective.png)

## 3) 目標地區 {#_3-target-geo}

搜尋並選擇要定向的國家或地區。已選國家會以標籤(chip)形式顯示,標題會實時顯示已選數量(例如 `1/20`)。每個廣告系列最多可添加 **20 個**地區。

**Retargeting Audience（可選）**

在目標地區下方,你可以附加 **Retargeting Audience**,以重新觸達你已知的用戶。點擊 **Create Audience** 建立一個(在至少建立一個之前,你會看到 *「No audience available」*)。留空則僅按地區定向。

> **提示：** 保持地區與素材語言一致。若你定向多個需要不同語言的市場，請為每個市場準備對應的素材（或素材語言）。參見 [步驟 6：素材](#_6-creative)。

![步驟 3——搜尋並選擇國家(最多 20 個);如有 Retargeting Audience 可附加](/img/onboarding/campaign-step3-geo.png)

## 4) 出價與日預算 {#_4-bid-daily-budget}

**出價策略**——請選擇其一：

- **oCPM**(Optimized CPM,*建議*——預設選取)：你設定期望的**每目標事件成本**,AdWave 朝此目標優化投放。最適合效果 / 以 CPA 為導向的廣告系列。
- **CPM**：你設定**最高 CPM 出價**——每千次展示願意支付的上限。最適合觸達與品牌認知。

**出價**

輸入你的出價金額。AdWave 會在欄位旁顯示 **Suggested Bid**——一個隨廣告格式與市場變化的實時建議;你可以高於或低於它出價。

> **注意：** 「eCPM 只改變我們的出價方式。你仍按 CPM 計費,可能高於或低於你的目標出價。」 競價中的實際出價可能低於你的上限而成交。

**日預算**

以美元（USD）設定每日花費上限。AdWave 會建議一個最低值,讓算法每天有足夠數據來學習與優化：

- **oCPM：** 將日預算設為約**出價的 100 倍**以獲得最佳學習效果(最低約 **50 倍**)。
- **CPM：** 日預算最低為**目標出價的 20 倍**。

![步驟 4——oCPM(預設)設定每目標事件成本;Suggested Bid 隨廣告格式實時更新](/img/onboarding/campaign-step4-bid.png)

## 5) 排期 {#_5-schedule}

- **開始日期：** 預設為現在(你的帳戶時區,UTC+0);也可安排未來開始。
- **結束日期：** 選擇一個日期,或使用**快速選擇週期**設定從開始日期起 **3D / 7D / 14D / 30D / 60D / 90D** 的固定時長——或用 **Custom Cycle** 自行輸入天數。

> **注意：** 排期面板顯示兩個時鐘——你帳戶時區(UTC+0)的 **Actual publish time**,以及你瀏覽器時區的 **Local time**——讓跨時區的廣告主可以確認投放究竟何時開始。

![步驟 5——快速選擇週期(3D–90D)或 Custom Cycle,附雙時區確認](/img/onboarding/campaign-step5-schedule.png)

## 6) 素材 {#_6-creative}

> **注意：** 請先在 [步驟 2](#_2-objective-ad-format) 選擇廣告格式。素材欄位會隨格式而變化。

點擊 **添加素材（[格式]）** 以新增一個素材區塊。你可以**一次上傳多張圖片——最多 20 張**。

對每個素材：

- **素材語言：** 設定語言（如 EN）。勾選 **「本廣告系列的所有素材都使用此語言」** 可套用於每個素材。
- **目標 URL：** 選擇落地頁。勾選 **「本廣告系列所有素材共用一個 URL」** 可複用單個 URL，或使用 **添加落地頁** 註冊新的 URL。

各格式專屬欄位：

| 格式 | 素材 | 規格 |
| --- | --- | --- |
| **Pop** | 僅目標 URL | 無需圖片——Pop 直接呈現你的落地頁 |
| **Push** | 圖示 + 主圖 + 標題 + 描述 | 圖示：JPEG/PNG/JPG，192×192，≤ 200 KB。主圖：JPEG/PNG/JPG，≤ 720 KB，尺寸 492×328 / 360×240 / 720×480。標題 ≤ 30 字元,描述 ≤ 40 字元。 |
| **Display** | 主圖 + 目標 URL | JPEG/PNG/JPG/GIF，≤ 500 KB，尺寸 300×250 / 320×50 / 728×90 / 468×60 / 160×600 / 300×100 |
| **Native** | 主圖 + 標題 + 描述 + 目標 URL | JPEG/PNG/JPG，≤ 500 KB，尺寸 300×250 / 300×100 / 320×50 / 728×90 / 468×60 / 160×600 |

> **提示：** 關於完整的素材指引、促銷／角度測試與範例，參見 [素材要求與範例](/hk/adwave/creative-requirements)。

![步驟 6——一個 Push 素材:符合規格的圖示 + 主圖、標題/描述,以及從你已註冊的落地頁中選取的目標 URL](/img/onboarding/campaign-step6-creative-push.png)

## 發佈 {#launch}

沒有單獨的**人工**審核步驟——但你會有一次最終的自我檢視。**Launch**(右上角)在每個步驟完成之前一直停用;當你點擊它時,AdWave 會開啟一個 **Campaign Summary**,列出你的產品、目標事件、廣告格式、地區、出價、預算、排期與素材。只有在你點擊 **Confirm** 之後,廣告系列才會被建立。

![點擊 Launch 會開啟 Campaign Summary——只有在你點擊 Confirm 後,廣告系列才會被建立](/img/onboarding/campaign-launch-summary.png)

**發佈前檢查清單：**

- ✅ 已選擇產品（且已啟用）
- ✅ 廣告系列名稱遵循建議格式
- ✅ 已設定目標事件（Register / FTD / Bet / LP Click）
- ✅ 已選擇廣告格式
- ✅ 至少添加一個目標地區（≤ 20）
- ✅ 已設定出價策略、出價與日預算（oCPM ≈ 出價的 100 倍,或 CPM ≥ 出價的 20 倍）
- ✅ 已排期開始（及結束/週期）
- ✅ 素材已按規格添加，並設定語言與目標 URL

## 上線後：需監控的內容 {#after-launch-what-to-monitor}

**投放**

- 展示、花費、CPM
- 勝率（如可用）
- 地區分佈 vs 預期

**互動**

- 點擊、CTR
- 極高展示 + 幾乎零點擊 → 排查庫存質素

**成效**

- 轉化（Register / Deposit）
- CPA / ROAS（如已連接）

## 疑難排解

::: details 我的產品在步驟 1 無法選取
只有**已啟用**的產品才會顯示為可選。產品在其 Web Tracker 收到首個事件之前一直處於 **Inactive** 狀態——請先安裝並驗證追蹤器(參見 [安裝 Web Tracker](/hk/tracking/web-tracker/install)),再返回本流程。
:::

::: details Launch 按鈕變灰
**Launch** 在每個步驟——產品、目標與廣告格式、目標地區、出價與日預算、排期以及素材——完成之前一直停用。左側導覽中高亮的步驟編號顯示你目前所在位置;完成未完成的部分即可啟用 Launch。
:::

::: details 點擊 Launch 後會發生甚麼?
點擊 **Launch** 會開啟一個 **Campaign Summary** 供你檢視。只有在你點擊 **Confirm** 之後,廣告系列才會被建立——請把該摘要當作定向、出價、預算與排期的最終檢查。
:::
