# 廣告格式與尺寸

網站直裝支援 Banner、Native、In-page Push、Pop 和 Push。建立 Banner 版位時，請依介面選項選擇尺寸，並確認頁面容器及 GAM 或 Prebid.js 的尺寸對應一致。

<div class="adflow-table" role="region" aria-label="廣告格式" tabindex="0">

| 格式 | 常見用法 |
| --- | --- |
| Banner | 固定尺寸橫幅。 |
| Native | 融入資訊流等頁面內容。 |
| In-page Push | 在頁面內顯示通知樣式廣告。 |
| Pop | 依接入指南指定的互動觸發。 |
| Push | 依指南設定並檢查瀏覽器權限。 |

</div>
