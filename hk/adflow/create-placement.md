# 建立帳號、網站和廣告版位

如果你準備將 AdFlow JS Tag 直接安裝到網站，請從這裡開始。使用自有 GAM 或 S2S 時，帳號、識別碼和版位設定以[所選的接入指南](./choose-integration)為準。

## 開始前

準備一個可登入的 AdFlow Publisher 帳號、一個可安裝及測試程式碼的網頁，以及要上線的廣告位置。先確認該位置的[廣告格式與尺寸](./ad-formats)。

## 1. 建立帳號

開啟 AdFlow 註冊頁面，驗證電子郵件，並依頁面提示填寫帳號和公司資料。完成後登入，進入網站與廣告版位管理。

## 2. 建立網站和廣告版位

1. 在網站與廣告版位管理中建立網站，填入實際接入的網域。
2. 在該網站下建立廣告版位，選擇符合網頁用途的格式。Banner 還需選擇寬度與高度。
3. 開啟版位的安裝程式碼，記下網站、版位 ID 和要安裝的網頁，並準備共用指令碼和版位程式碼。

## 完成標誌

版位屬於正確的網站，格式符合放置位置，且你已取得所需的安裝程式碼。接著開啟[網站直接安裝 AdFlow JS Tag](./adflow-sdk)，再依照[驗證接入與上線](./verify-and-launch)檢查第一則廣告。
