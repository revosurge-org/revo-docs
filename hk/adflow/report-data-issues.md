# 報表沒有資料或數字不一致

先確認問題出在請求、廣告顯示或報表統計。準備對應的網站、版位和可以重現問題的時間範圍。

## 1. 報表空白

1. 核對帳號、網站、版位、國家篩選條件和日期範圍，然後重新查詢。
2. 檢查頁面顯示的報表產生時間，確認報表是否涵蓋該時段的資料。
3. 依照[驗證接入與上線](./verify-and-launch)，分別確認真實請求和實際廣告顯示。若只有請求，請依照[有請求，但沒有廣告顯示](./no-ad-display)繼續排查。

## 2. 儀表板、維度表或 GAM 的數字不同

1. 對齊日期、時區、篩選條件和版位對應。
2. 核對同一種指標，並確認指標定義。例如，用圖表中某天的請求量對照「日期」維度中同一天的請求量。
3. 若差異仍存在，記下兩個來源、各自的指標和數值、時間範圍、報表產生時間與篩選條件截圖，交給客戶經理核對。

如需核對每月應收和付款安排，請開啟[帳單與每月對帳](./billing)。
