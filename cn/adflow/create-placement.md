# 创建账号、网站和广告位


<p>如果你准备把 AdFlow JS Tag 直接装到网站上，从这里开始。自有 GAM 和 S2S 的账号、标识及版位配置，以<a href="./choose-integration">所选的接入指南</a>为准。</p>
<h2 id="开始前">开始前</h2>
<p>准备一个可登录的 AdFlow Publisher 账号、一页能安装和测试代码的网站，以及一个想上线的广告位置。先确认该位置的<a href="./ad-formats">广告格式与尺寸</a>。</p>
<h2 id="1-创建账号">1. 创建账号</h2>
<p>打开 AdFlow 注册入口，验证邮箱并按页面提示填写账户与公司资料。完成后登录，进入网站与广告位管理。</p>
<h2 id="2-创建网站和广告位">2. 创建网站和广告位</h2>
<ol>
<li>在网站与广告位管理中创建网站，填写实际接入的域名。</li>
<li>在该网站下创建广告位，选择和页面用途匹配的格式。Banner 还需要选宽度与高度。</li>
<li>打开广告位的安装代码，记录网站、广告位 ID 和要安装的页面。准备好共用脚本和广告位代码。</li>
</ol>
<h2 id="完成标志">完成标志</h2>
<p>广告位属于正确的网站，格式与放置位置一致，你已取得这次需要安装的代码。接下来打开<a href="./adflow-sdk">网站直接安装 AdFlow JS Tag</a>，再按照<a href="./verify-and-launch">验证接入与上线</a>检查第一条广告。</p>
