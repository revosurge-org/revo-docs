# 报表没数据或数据对不上


<p>先确定问题发生在请求、展示还是报表统计。准备对应网站、广告位及可以复现的时间范围。</p>
<h2 id="1-报表为空">1. 报表为空</h2>
<ol>
<li>核对账号、网站、广告位、国家筛选与日期范围，重新查询。</li>
<li>检查页面显示的报表生成时间，确认该时间段的数据是否已包含。</li>
<li>对照<a href="./verify-and-launch">验证接入与上线</a>，分别确认真实请求和实际展示。若只有请求，继续按<a href="./no-ad-display">有请求，但没有广告展示</a>排查。</li>
</ol>
<h2 id="2-看板维度表或-gam-数字不同">2. 看板、维度表或 GAM 数字不同</h2>
<ol>
<li>对齐日期、时区、筛选和版位映射。</li>
<li>核对同一种指标，并确认业务口径。比如，用图中某天的请求量对照「日期」维度中那天的请求量。</li>
<li>仍有差异时，记录两个来源、各自指标、数值、时间范围、报表生成时间和筛选截图，交给客户经理核对。</li>
</ol>
<p>需要核对月度应收和付款安排时，打开<a href="./billing">账单与月度对账</a>。</p>
