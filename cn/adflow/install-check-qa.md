# 安装代码失败 QA

安装检查未收到该广告位的匹配请求？请按下面顺序排查。此检查只查询真实请求，不会发起测试流量。

::: tip 什么算安装检查通过？
目标网站上的广告位发出的真实 Bid Request 到达 Prebid Server，即视为安装检查通过。没有广告返回、`NO_BID`、竞价过滤或暂未展示，是后续竞价与展示问题，不等于代码没有安装成功。
:::

## 1. 确认代码已发布，并打开目标页面 {#publish}

只点击网站后台的「保存」或「发布」，不会保证已经打开的网页自动刷新。请打开或刷新已发布的、安装该广告位的正式页面。如果站点有缓存或 CDN，请确认它已提供最新页面代码。预览页、测试环境与正式页可能不同。

## 2. 核对两段代码与广告位 {#codes}

### 共用脚本和广告位代码都在目标页面吗？

请对照 AdFlow 的两步安装代码。共用脚本应正确加载，目标广告位代码也须在同一页面；不要只安装其中一段，也不要放错页面模板。同一站点模板的共用脚本只安装一次。

确认代码取自 AdFlow 中对应网站和广告位的正式代码，而非示例。两步安装方式见[接入指南](./integration-guide#adflow-usage)。

### 账号与广告位 ID 是否匹配？

确认 `data-account-id` 和 `data-placement-id` 与本次检查的账号、广告位一致，且该广告位属于当前选择的网站。多个账号或广告位的代码不要混用。不确定时，请从 AdFlow 对应广告位重新复制代码。

## 3. 触发一次真实广告请求 {#trigger}

刷新页面后，确认广告位所在区域实际加载。若网站使用懒加载、单页路由或需要交互才能触发广告位，请滚动至广告位或完成对应操作。在浏览器的 **Network** 面板确认有请求，再回 AdFlow 重新执行安装检查。

## 4. 查看浏览器拦截与报错 {#browser}

可请网站开发者打开浏览器开发者工具的 **Network** 与 **Console**，依次检查：

- AdFlow 脚本是否已加载并执行？
- 是否有 JavaScript 错误？
- 内容安全策略（CSP）是否拦截脚本或请求？
- 是否有网络请求失败，或浏览器扩展拦截？

请开发者修复站点或网络配置问题。诊断时可在自己的测试浏览器临时排除扩展拦截影响，不应要求所有访客关闭安全设置。

可参考[接入指南中的诊断工具](./integration-guide#adflow-diagnostic)。收到请求后仍有竞价或展示问题时，请使用对应的[广告格式调试器](./integration-guide#adflow-sdk)或 [S2S 调试器](./s2s-debugger)。

## 5. 稍后重试，确认检查对象 {#retry}

请求记录可能有短暂处理延迟。请稍后再试，并确认 AdFlow 当前选择的网站、广告位与刚才实际访问的页面一致。

新建广告位的外部 ID 可能尚未同步到检查所用的数据，建议创建后等待 1-2 分钟再触发检查；从请求发出到检查可查通常也存在分钟级延迟，刚触发的请求可能需要稍等才会出现。

如果页面已正确安装但检查仍失败，请在浏览器 **Network** 面板确认是否有发往 Prebid Server 的请求，以及该请求是否携带了正确的 publisher ID 与 placement ID。

当前未查到匹配请求不代表完整历史中从未出现请求，也不能直接判定唯一原因。如果是检查操作本身失败，请稍后重新检查，不要据此认定代码安装失败。

::: tip 检查结果显示"未知"（unknown）时
当报表通道暂时不可用，检查会返回"未知"而非"未查到"。这不是安装问题，而是系统暂时无法核查，请稍后再试；若持续出现，请按下方联系方式提交客服。
:::

## 6. 确认账号、网站与广告位状态 {#states}

安装检查只会查询状态正常对象上的真实请求，以下状态会导致本次检查查不到匹配请求：

- **广告位状态不是 `active`。** 新建广告位默认为 `pending`（待验证），需代码安装成功并触发验证后才变为 `active`；若为 `disabled`（已停用），请在 AdFlow 后台启用或联系管理员。
- **网站状态不是 `active`。** 检查要求对应网站（Website）处于 `active` 且未被删除；若网站被停用，该网站下所有广告位的检查都会失败。请在 AdFlow 网站管理中确认网站已激活。
- **账号已被禁用。** 账号被禁用后，所有广告位的检查请求都不会被查询。请确认 AdFlow 账号处于 `active`；若显示已禁用，联系管理员恢复。

## 仍然无法解决？ {#help}

请通过 AdFlow 右下角的现有客服联系人工支持，并提供：

- 网站域名、实际页面 URL。
- 广告位 ID。
- 代码发布时间、最近检查时间及对应时区。
- 相关 Network / Console 截图。
- 广告位与网站的当前状态（`pending` / `active` / `disabled`）。
- 检查结果类型（收到真实 Bid Request / 未查到 / 未知）。
- 页面代码中的 `data-account-id`、`data-placement-id` 值，以及是否与 AdFlow 后台显示一致。

请勿提供账号密码、密钥或访客隐私数据。
