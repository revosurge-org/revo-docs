# 素材

**面向：** 为第一个广告系列准备广告的广告主和设计师。

素材就是玩家看到的广告。AdWave 会让你的素材互相比拼，把预算倾斜给表现最好的，并下线不再起效的。素材越多样，AdWave 就越快找出胜出的那几组。

## 1. 需要多少素材 {#_1-how-many-creatives-you-need}

上线前准备 **8–10 组素材**。

- **学得更快：** 素材之间差异越明显，AdWave 学得越快。
- **CPA 更低：** 选择越多，找到更便宜转化的空间就越大。
- **不易疲劳：** 某一组跑不动了，可以换上其他组。

::: tip 保持素材新鲜
当某个素材的 CTR 或转化开始下降时，**每 2 周新增 2–3 组**。
:::

## 2. 什么算一组素材 {#_2-what-makes-a-creative-set}

一组素材就是广告的一个版本，它至少在下面某个维度上和其他组不同。先从在你网站上转化已经不错的优惠和文案入手。

| 维度 | 示例 |
| --- | --- |
| **优惠** | 首充 100% 奖励、50 次免费旋转、2% 返水、VIP 计划、限时活动 |
| **主题** | 老虎机、Crash、真人娱乐场、体育博彩、扑克 |
| **文案** | 奖池金额、快速提现、安全持牌、新玩家专享、倒计时 |
| **视觉** | 真人荷官或模特、游戏画面、大奖画面、体育明星 |
| **本地化** | 语言、本地游戏、本地支付方式、本地节日 |

**一次只测一个变量。** 先找出最好的优惠，再为这个优惠测试不同切入点，最后测视觉。

## 3. 各广告格式的规格 {#_3-specs-by-ad-format}

| 格式 | 需要提供 | 规格 |
| --- | --- | --- |
| **Pop** | 落地页 URL | 不需要图片，Pop 会直接打开你的落地页。每个优惠一个 URL，语言与市场对应 |
| **Push** | 品牌 Logo + 图片 + 标题 + 描述 | Logo：JPG/PNG，192×192，≤ 200 KB。图片：JPG/PNG，360×240，≤ 720 KB。标题 ≤ 30 个字符，描述 ≤ 40 个字符（表情符号不计入） |
| **Display** | 横幅图片 | GIF/JPG/PNG，≤ 500 KB。**先从** 300×250、300×100、320×50 开始。AdWave 也支持 728×90、468×60 和 160×600 |
| **Native** | 图片 + 标题 + 描述 | JPG/PNG，≤ 500 KB。尺寸：300×250 |

<!-- Display sizes verified in AdWave on 2026-09-28. TODO (Product): verify Push and Native accepted sizes the same way. -->

::: tip Pop 和 Display 建议用动态素材
动态素材（Display 用 GIF）通常能带来更多点击和转化。小尺寸横幅请重新排版，不要把大图直接缩小。
:::

每个素材都要加上各市场要求的法律声明，例如 **18+**、“理性博彩”（Play responsibly）和“受条款约束”（T&Cs apply）。

## 4. 第一轮示例 {#_4-example-first-round}

以马来西亚市场为例，共 2 个优惠、3 种语言（英文 / 中文 / 马来文）：

| 格式 | 测试什么 | 组数 |
| --- | --- | --- |
| **Pop** | 2 个优惠 × 2 种视觉（真人荷官、游戏画面） | 4 |
| **Display** | 2 个优惠，每个都做 300×250、300×100 和 320×50 | 2 |
| **Push** | 2 种文案切入点（倒计时、大奖） | 2 |
| **合计** | | **8 组，约 28 个文件** |

各格式的效果预览，参见[素材要求与范例](/cn/handbook/creative-requirements)。

## 5. 上传和管理素材 {#_5-upload-and-manage-creatives}

你可以在[创建广告系列](./create-campaign#_6-creative)时添加素材，也可以随时在左侧菜单的 **Creative** 中上传和查看。

![Creatives 列表，显示每个素材的格式、尺寸、语言、使用情况和效果](/img/handbook/creatives-list.png)

Pop 素材以落地页 URL 列出。可以用筛选器（**All Formats**、**All Sizes**、**All Usage**、**All Language**）查找素材，再按 **Spend** 或 **CTR** 排序，看看哪些素材效果好。

::: tip 为每个素材设置语言
语言标为 **Unspecified** 的素材，很难按市场做对比。点击 **Language** 列里的铅笔图标即可设置。
:::
