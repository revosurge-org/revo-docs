# 优化与放量

**面向：** 已有至少一周广告系列数据的广告主和媒介采买。

广告系列跑了一周左右，数据就足够用来优化了。先优化，再给有效的部分放量。

## 1. 什么时候可以放量 {#_1-when-a-campaign-is-ready-to-scale}

以下条件全部满足时，就可以放量：

- ✅ 已投放至少 **7 天**
- ✅ **Cohort** 视图中的 CPA 不高于目标 <!-- TODO (Product): same day-7 cohort maturity question as first-week.md -->
- ✅ 每天都能花掉大部分日预算
- ✅ 至少有一组素材明显优于其他组

如果 CPA 高于目标，先优化，再放量。

## 2. 优化 {#_2-optimise}

按下表顺序逐项调整。每次只改一处，等 2–3 天再复查。

| 调整项 | 怎么做 |
| --- | --- |
| **素材** | 暂停最弱的几组。以表现最好的一组为基础新增 2–3 组：优惠不变，换新的视觉或文案 |
| **优惠** | 如果所有素材的 CPA 都偏高，问题可能出在优惠本身。换一种奖励或促销来测试 |
| **落地页** | 如果 CTR 不错但注册少，试试另一款预落地页模板，或缩短表单 |
| **地区** | 把 CPA 差异很大的地区拆成独立的广告系列，这样每个地区都能单独出价 |
| **出价** | 如果 CPA 远低于目标但量起不来，把出价提高 10–20% |

## 3. 放量 {#_3-scale}

- **逐步提高日预算**，每 2–3 天提高约 20–30%。一次加太多，可能导致学习重新开始。
- **日预算保持在出价的 100 倍左右。** 提高出价时，预算也要同步提高。
- **新增地区要新建广告系列**，不要加进已经跑得好的广告系列，这样才能对比效果。
- **用同样的优惠试第二种广告格式。** 不同格式能触达不同的玩家。
- **提前备足余额。** 提高预算之前，先请客户经理充值。

## 4. 转向更深的目标 {#_4-move-to-a-deeper-goal}

Register 广告系列跑稳之后，再把目标往更接近收入的方向推进：

1. 确认充值已通过 **S2S** 或 **Partner Postback** 追踪（[接入追踪](/cn/tracking/overview#_2-2-which-system-holds-your-conversion-data)）。
2. 新建一个以 **FTD** 为目标事件的广告系列。
3. 用 **受众（Audience）** 对已注册但未充值的玩家做再营销。参见[受众 → 受众细分](/cn/audience/segments)。
