# 从这里开始：上线你的第一个广告系列

**面向：** 首次在 RevoSurge 上投放的自助广告主，包括企业主、营销人员和媒介采买。无需程序化广告经验。

读完这本手册，你的账户已完成充值，产品能记录转化，广告系列也已在 **AdWave**（RevoSurge 的广告投放工具）中上线。

## 1. 运作方式 {#_1-how-it-works}

RevoSurge 会在大量网站和 App 上向玩家展示你的广告。它从你回传的转化（注册、充值）中学习，再去找更多相似的人。追踪做得越好，广告系列的效果就越好。

先花约 30 分钟填好下方的[上线准备表](#_2-fill-in-your-launch-worksheet)，再按顺序完成下面七个步骤。第 1–5 步完成上线，第 6–7 步在上线之后进行。

| 步骤 | 做什么 | 由谁负责 | 用时 |
| --- | --- | --- | --- |
| **1. 账户与钱包** | 注册账户，再通过客户经理给钱包充值 | 你 + 客户经理 | 10 分钟 + 到账时间 |
| **2. 接入追踪** | 把网站登记为产品，然后安装追踪 | 你 + 开发者 | 当天至 5 天 |
| **3. 落地页** | 准备玩家点击广告后进入的页面 | 你 | 1 天 |
| **4. 素材** | 准备 8–10 组素材 | 你或设计师 | 1–2 天 |
| **5. 创建广告系列** | 在 AdWave 中创建并上线广告系列 | 你 | 20 分钟 |
| **6. 投放第一周** | 查看投放和转化情况，再决定放量、调整还是停投 | 你 | 每天 10 分钟 |
| **7. 优化与放量** | 提升效果，把有效的投放做大 | 你 | 每周 |

第 2–4 步可以并行：开发者安装追踪时，你可以同步准备落地页和素材。

AdWave 首页会跟踪你的设置进度：每完成一步就会变绿，最后解锁 **Create Campaign**。

![AdWave 引导清单：Create Product、Setup Web Tracker、S2S Postback 和 Create Campaign](/img/handbook/adwave-onboarding-wizard.png)

::: info 追踪要多久？
如果玩家在你的网站上注册，只装 **Web 追踪器**就够了，当天就能上线。如果要按你自己后端记录的充值来优化，开发者还需要接入 **S2S**，大约需要 2–5 天。参见 [追踪概述 → 选择你的配置方案](/cn/tracking/overview#_2-choose-your-setup)。
:::

## 2. 填写上线准备表 {#_2-fill-in-your-launch-worksheet}

请在打开 AdWave **之前**填好这张表。设置过程中要做的每个决定都在表里，而且每一部分都对应 AdWave 中的一个步骤，到时直接填入想好的内容就行。把它发给开发者和客户经理，他们想问的问题，大多能在表里找到答案。

### 2.1 你的业务 {#_2-1-your-business}

用于：**Product → Create Product**

| 问题 | 怎么选 |
| --- | --- |
| 产品名称 | 在报表里一眼就能认出的名字，例如 `BrandX Casino` |
| 主域名 | 需带上 `https://`，例如 `https://brandx.com` |
| 所有落地页域名 | 列出广告会导流到的**每一个**域名，包括预落地页、镜像站和跳转域名。未登记的域名无法投放 |
| 每个落地页的 Funnel Type | **Direct Register** = 玩家直接在这个页面注册。**Redirect Register** = 这个页面把玩家跳转到注册页。两种 Download 类型同理，用于 App 安装 |
| 充值币种 | 后台结算充值所用的币种。如果用加密货币结算，就选加密货币 |

### 2.2 目标与追踪 {#_2-2-goal-and-tracking}

用于：**Product → Setup Wizard** 以及广告系列的 **Target Event**

| 问题 | 你的答案 | 怎么选 |
| --- | --- | --- |
| 玩家落在网页还是 App？ | 网页 / App / 两者都有 | App 广告系列还需要 **AppsFlyer** |
| 目标事件 | Register / FTD / Bet / Landing Page Click | 如果历史转化不多，先从 **Register**（注册）开始。选 **FTD**（首充）的前提是充值事件已经在追踪。参见 [创建广告系列 → 目标事件](./create-campaign#_2-objective-and-ad-format) |
| 充值记录在哪里？ | 我的后端 / 联盟平台 / AppsFlyer | 这决定了追踪方式（见下表） |
| 追踪方式 | | 对照下表选择 |
| 谁来安装追踪？ | 姓名 + 联系方式 | 能在网站上添加脚本的开发者 |

| 如果… | 你需要 | 一般用时 |
| --- | --- | --- |
| 网页，目标 = Register | Web 追踪器 | 当天 |
| 网页，目标 = FTD，数据在联盟平台 | Web 追踪器 + Partner Postback | 当天 |
| 网页，目标 = FTD，数据在自己的后端 | Web 追踪器 + S2S | 约 2–3 天 |
| App | Web 追踪器 + AppsFlyer（追踪充值另需 S2S） | 约 3–5 天 |

详见[接入追踪](/cn/tracking/overview)。

### 2.3 投放地区 {#_2-3-where-to-advertise}

用于：广告系列的 **Target Geo**

| 问题 | 怎么选 |
| --- | --- |
| 国家或地区 | 每个广告系列最多 **20** 个。首次测试建议从 1–3 个你熟悉的市场开始 |
| 各市场的广告语言 | 使用各市场的当地语言。如果不同市场语言不同，就为每种语言分别准备素材，或者每种语言单独建一个广告系列 |

### 2.4 广告格式、出价与预算 {#_2-4-ad-format-bid-and-budget}

用于：广告系列的 **Ad Format**、**Bid & Daily Budget** 和 **Schedule**

**每个广告系列选一种广告格式：**

| 格式 | 是什么 | 适合 | 所需素材 |
| --- | --- | --- | --- |
| **Pop** | 在新窗口中打开你的落地页 | 快速拿到转化量 | 不需要，只要落地页 URL |
| **Push** | 通知样式的广告 | 触达和召回 | Logo、图片、标题、描述 |
| **Display** | 固定在页面某个位置的横幅 | 提升曝光 | 横幅图片 |
| **Native** | 看起来像网站自身内容的广告 | 更高的点击率 | 图片、标题、描述 |

**出价与预算：**

| 问题 | 怎么选 |
| --- | --- |
| 出价策略 | 选 **oCPM**（标有 *Suggested*）。你设定每个目标事件愿意付的成本，AdWave 会去找最可能转化的流量 |
| 出价（美元） | 使用 oCPM 时，出价就是你为每个目标事件愿意付的成本，也就是目标 CPA。可以对照 AdWave 显示的 **Suggested Bid** |
| 日预算（美元） | oCPM：约为出价的 **100 倍**，至少 **50 倍**。例如出价 $2.50，日预算约需 $250，不低于 $125。CPM：至少为出价的 **20 倍** |
| 测试总预算（美元） | 日预算 × 测试天数，也就是你需要请客户经理充值的金额 |
| 开始日期 | 立即开始，或选择未来某一天 |
| 结束日期 / 周期 | 7、14、30、60 或 90 天。首次测试选 **14 天**，数据量足以判断效果 |

### 2.5 素材 {#_2-5-creatives}

用于：广告系列的 **Creative** 部分

| 格式 | 素材 | 规格 |
| --- | --- | --- |
| **Pop** | 落地页 URL | 每个优惠一个 URL，不需要图片 |
| **Push** | 品牌 Logo | JPG/PNG，192×192，≤ 200 KB |
| | 图片 | JPG/PNG，360×240，≤ 720 KB |
| | 标题 / 描述 | ≤ 30 个字符 / ≤ 40 个字符 |
| **Display** | 横幅 | GIF/JPG/PNG，≤ 500 KB。先从 300×250 · 300×100 · 320×50 开始（AdWave 也支持 728×90 · 468×60 · 160×600） |
| **Native** | 图片 + 标题 + 描述 | JPG/PNG，≤ 500 KB，300×250 |

上传前请确认：

- ✅ 已准备 **8–10 组素材**，在优惠、视觉和文案上各有差异，方便 AdWave 找出最好的一组
- ✅ 每个素材都使用对应市场的语言
- ✅ 广告里的优惠（例如“首充 100% 奖励”）与落地页一致
- ✅ 文件符合上面的大小和尺寸限制

素材组的定义、示例和完整规格，参见[素材](./creatives)。

### 2.6 落地页 {#_2-6-landing-page}

用于：广告系列的 **Destination URL**

逐项检查页面：

- ✅ 在移动网络下 2 秒内加载完成
- ✅ 优惠和语言与广告一致
- ✅ 只有一个明确的操作（注册或充值），不用滚动就能看到
- ✅ 注册表单只收集必要信息

参见[落地页与转化路径](./landing-page)。

### 2.7 上线前检查清单 {#_2-7-ready-to-launch-checklist}

- ✅ 已通过客户经理给钱包充值，金额覆盖全部测试预算
- ✅ 产品在 **Manage Product** 中显示为 **Active**
- ✅ 目标事件已在追踪（能在产品的 **Event Stream** 里看到）
- ✅ 广告指向的每个域名都已登记在产品下
- ✅ 地区、语言和素材一一对应
- ✅ 出价、日预算和排期已确定
- ✅ 第一周每天都有人看一次效果

都勾上了？前往[创建广告系列](./create-campaign)。

## 4. 获取帮助 {#_4-get-help}

- **追踪卡住了？** 打开 **Product → Setup Wizard** 中的 **Event Stream**，看看网站正在发送什么；也可以参见 [Web 追踪器 → 疑难排查](/cn/tracking/web-tracker/install#troubleshooting)。
- **还是没解决？** 联系客户经理，并附上填好的[上线准备表](#_2-fill-in-your-launch-worksheet)。他们想问的问题，表里大多已经有答案。
