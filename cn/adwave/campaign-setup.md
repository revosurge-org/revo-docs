# 广告系列设置

**面向：** 在 AdWave 投放广告的 UA 经理、广告系列运营与增长团队。

广告系列设置是一个单页、逐步进行的流程，带你在同一处完成从创建产品到上线投放（含素材）的全过程。

## 前提条件 {#prerequisites}

广告系列创建**受数据配置限制**。在 AdWave 引导页（**接入你的数据**）上，*创建广告系列* 会一直锁定，直到你完成步骤 1–3。开始前请确保：

- **已创建产品。** 创建**产品**（你要推广的应用或网站），并填写其域名、追踪器 ID 与充值汇率。
- **Web 追踪器已激活。** 在 Web 追踪器收到首个事件之前，产品处于 **Inactive（未激活）** 状态；只有**已激活**的产品才能在广告系列流程中选择。参见 [安装 Web 追踪器](/cn/tracking/web-tracker/install)。
- **转化事件已追踪。** 你用于优化的目标事件（如 Register、Deposit）必须已通过追踪流入。参见 [追踪 → 概述](/cn/tracking/overview)。
- **钱包已充值。** 你的**钱包**余额充足。参见 [充值与钱包](/cn/growth/funding-wallet)。
- **素材已就绪。** 素材已按规格准备好。参见 [素材要求与范例](/cn/adwave/creative-requirements)。

> **提示：** 你可在**管理产品**中查看产品状态——**Tracker Status（追踪器状态）** 列显示 Active / Inactive，*Data Setup（数据配置）* 显示有多少事件处于激活状态。

## 1) 产品 {#_1-product}

选择你要推广的**产品**。每张卡片显示产品名称及其 URL。

> **注意：** “未激活的产品需先激活才能投入使用。” 若所需产品尚未激活，请先激活，再返回本流程。

![步骤 1 —— 已激活的产品可供选择；未激活的产品在分隔线下方以灰色显示](/img/onboarding/campaign-step1-product.png)

## 2) 目标与广告格式 {#_2-objective-ad-format}

**广告系列名称**

输入用于报表的可读名称。AdWave 建议一套命名格式以保持广告系列一致：

> 建议格式：**地区 + 促销 + 广告格式 + 开始日期**——例如 `IN_Register_Display_20260126`。

**目标事件**

选择本广告系列要优化的转化事件。该事件用于衡量转化并计算广告系列的 **CPA**。请从以下选一：

- **Register**
- **FTD (First-Time Deposit)**
- **Bet**
- **LP Click**

**广告格式**

选择一种格式。每种格式的素材要求不同（见 [步骤 6](#_6-creative)），建议出价也不同：

- **Pop** — 以覆盖层或新窗口形式出现的广告。极为吸睛；适合促销与以转化为目标的广告系列。
- **Push** — 直接推送到用户设备的通知式广告。适合再互动与持续触达用户。
- **Display** — 放置在固定位置（如侧边栏或页首）的横幅式广告。适合强曝光与广泛的品牌认知。
- **Native** — 无缝融入内容信息流的广告。干扰更小、更具吸引力；适合追求更高点击率。

![步骤 2 —— 广告系列名称、目标事件（Register / FTD / Bet / LP Click）与广告格式](/img/onboarding/campaign-step2-objective.png)

## 3) 目标地区 {#_3-target-geo}

搜索并选择要定向的国家或地区。所选国家会以标签（chip）形式显示，标题处显示实时计数（如 `1/20`）。每个广告系列最多可添加 **20 个**地区。

**再营销受众（可选）**

在目标地区下方，你可附加一个**再营销受众 (Retargeting Audience)**，以重新触达你已知的用户。点击 **Create Audience** 来创建（在至少存在一个之前，你会看到 *“No audience available”*）。留空则仅按地区定向。

> **提示：** 保持地区与素材语言一致。若你定向多个需要不同语言的市场，请为每个市场准备对应的素材（或素材语言）。参见 [步骤 6：素材](#_6-creative)。

![步骤 3 —— 搜索并选择国家（最多 20 个）；如有再营销受众可附加](/img/onboarding/campaign-step3-geo.png)

## 4) 出价与日预算 {#_4-bid-daily-budget}

**出价策略** —— 选择其一：

- **oCPM**（优化 CPM，*建议* —— 默认选中）：你设置期望的**单次目标事件成本**，AdWave 朝此优化投放。最适合效果 / CPA 导向的广告系列。
- **CPM**：你设置**最高 CPM 出价**——你愿意为每千次展示支付的上限。最适合覆盖与认知。

**出价**

输入你的出价金额。AdWave 会在输入框旁显示**建议出价 (Suggested Bid)**——随广告格式和市场变化的实时推荐；你可高于或低于它出价。

> **注意：** “eCPM 只改变我们如何出价。你仍按 CPM 计费，其可能高于或低于你的目标出价。”竞价中的实际出价可能低于你的上限成交。

**日预算**

以美元（USD）设置每日花费上限。AdWave 会建议一个最低值，以便算法每天有足够数据来学习并优化：

- **oCPM：** 将日预算设为约**出价的 100 倍**以获得最佳学习效果（最低约 **50 倍**）。
- **CPM：** 日预算最低为**目标出价的 20 倍**。

![步骤 4 —— oCPM（默认）设置单次目标事件成本；建议出价按广告格式实时更新](/img/onboarding/campaign-step4-bid.png)

## 5) 排期 {#_5-schedule}

- **开始日期：** 默认为现在（你的账户时区，UTC+0）；也可安排未来开始。
- **结束日期：** 选择一个日期，或使用**快速选择周期**从开始日期起设置 **3D / 7D / 14D / 30D / 60D / 90D** 的固定时长——或使用**自定义周期 (Custom Cycle)** 输入你自己的天数。

> **注意：** 排期面板显示两个时钟——你账户时区（UTC+0）下的**实际发布时间 (Actual publish time)** 与浏览器时区下的**本地时间 (Local time)**——以便跨时区广告主确认投放的确切开始时刻。

![步骤 5 —— 快速选择周期（3D–90D）或自定义周期，并带双时区确认](/img/onboarding/campaign-step5-schedule.png)

## 6) 素材 {#_6-creative}

> **注意：** 请先在 [步骤 2](#_2-objective-ad-format) 选择广告格式。素材字段会随格式而变化。

点击 **添加素材（[格式]）** 以新增一个素材块。你可以**一次上传多张图片——最多 20 张**。

对每个素材：

- **素材语言：** 设置语言（如 EN）。勾选 **“本广告系列的所有素材都使用此语言”** 可应用于每个素材。
- **目标 URL：** 选择落地页。勾选 **“本广告系列所有素材共用一个 URL”** 可复用单个 URL，或使用 **添加落地页** 注册新的 URL。

各格式专属字段：

| 格式 | 素材 | 规格 |
| --- | --- | --- |
| **Pop** | 仅目标 URL | 无需图片——Pop 直接呈现你的落地页 |
| **Push** | 图标 + 主图 + 标题 + 描述 | 图标：JPEG/PNG/JPG，192×192，≤ 200 KB。主图：JPEG/PNG/JPG，≤ 720 KB，尺寸 492×328 / 360×240 / 720×480。标题 ≤ 30 字符，描述 ≤ 40 字符。 |
| **Display** | 主图 + 目标 URL | JPEG/PNG/JPG/GIF，≤ 500 KB，尺寸 300×250 / 320×50 / 728×90 / 468×60 / 160×600 / 300×100 |
| **Native** | 主图 + 标题 + 描述 + 目标 URL | JPEG/PNG/JPG，≤ 500 KB，尺寸 300×250 / 300×100 / 320×50 / 728×90 / 468×60 / 160×600 |

> **提示：** 关于完整的素材指引、促销／角度测试与范例，参见 [素材要求与范例](/cn/adwave/creative-requirements)。

![步骤 6 —— 一条 Push 素材：符合规格的图标 + 主图、标题/描述，以及从已注册落地页中选定的目标 URL](/img/onboarding/campaign-step6-creative-push.png)

## 发布 {#launch}

没有单独的**人工**审核步骤——但你会有一次最终的自我复核。（右上角的）**发布** 在每一步完成前始终为禁用状态；当你点击它时，AdWave 会打开 **Campaign Summary**，列出你的产品、目标事件、广告格式、地区、出价、预算、排期与素材。只有在你点击 **Confirm** 后，广告系列才会创建。

![点击发布会打开 Campaign Summary —— 只有在点击 Confirm 后广告系列才会创建](/img/onboarding/campaign-launch-summary.png)

**发布前检查清单：**

- ✅ 已选择产品（且已激活）
- ✅ 广告系列名称遵循建议格式
- ✅ 已设置目标事件（Register / FTD / Bet / LP Click）
- ✅ 已选择广告格式
- ✅ 至少添加一个目标地区（≤ 20）
- ✅ 已设置出价策略、出价与日预算（oCPM ≈ 出价的 100 倍，或 CPM ≥ 出价的 20 倍）
- ✅ 已排期开始（及结束/周期）
- ✅ 素材已按规格添加，并设置语言与目标 URL

## 上线后：需监控的内容 {#after-launch-what-to-monitor}

**投放**

- 展示、花费、CPM
- 胜率（如可用）
- 地区分布 vs 预期

**互动**

- 点击、CTR
- 极高展示 + 几乎零点击 → 排查库存质量

**成效**

- 转化（Register / Deposit）
- CPA / ROAS（如已连接）

## 故障排查

::: details 步骤 1 里我的产品无法选择
只有**已激活**的产品才会显示为可选。在 Web Tracker 收到首个事件之前，产品始终为 **Inactive**——请先安装并验证追踪器（参见 [安装 Web Tracker](/cn/tracking/web-tracker/install)），再返回本流程。
:::

::: details 发布按钮为灰色
在每一步——产品、目标与广告格式、目标地区、出价与日预算、排期、素材——都完成之前，**发布** 始终为禁用状态。左侧导航中高亮的步骤号显示你所在的位置；完成未填写的部分即可启用发布。
:::

::: details 点击发布会发生什么？
点击 **发布** 会打开 **Campaign Summary** 供你复核。只有在你点击 **Confirm** 后，广告系列才会创建——请以该摘要作为对定向、出价、预算与排期的最终检查。
:::
