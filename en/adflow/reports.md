# View placement data and reports

> Planned for this release. Use these instructions once the corresponding features are live.

<p>Use the placement list to check for recent requests. Use reports to analyze traffic, impressions, and earnings by date, site, and placement. Have the site, placement, and date range ready before you start.</p>
<h2 id="requests-last-3-days">Check placement requests over the last 3 days</h2>
<p>In Websites and Placements, open the placement list for the site and find Requests (Last 3 Days). This metric shows whether the placement has received ad requests recently. To see actual impressions, open Reports.</p>
<h2 id="filter-a-report">Filter a report</h2>
<ol>
<li>Open Reports and select a date range, country, site, and placement.</li>
<li>Run the query and check the report generation time shown on the page.</li>
<li>Review total requests, total bids, average bid rate, impressions, clicks, earnings, and eCPM for the selected range. The bid rate tooltip explains the calculation and how missing values are shown.</li>
</ol>
<h2 id="trends-and-breakdowns">Review trends and breakdowns</h2>
<p>In Performance Trends, select request volume, bid volume, or bid rate as the primary or secondary metric to view daily changes. Use the breakdown table below to review details by date, placement, or other dimensions. To check a chart value, use the same filters and find the corresponding day in the Date breakdown.</p>
<h2 id="done">How to tell you’re done</h2>
<p>You can find the data for the selected placement and date range and match a day on the chart to the Date breakdown. If data is missing or the figures differ, see <a href="./report-data-issues">Report data is missing or mismatched</a>.</p>
