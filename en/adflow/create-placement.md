# Create an account, site, and ad placement

Start here if you plan to install the AdFlow JS Tag directly on your site. For your own GAM or S2S setup, follow [the integration guide you selected](./choose-integration) for the required account, IDs, and placement configuration.

## Before you start

Have an AdFlow Publisher account you can sign in to, a webpage where you can install and test code, and a location for the ad. Check the [ad format and size](./ad-formats) for that location.

## 1. Create an account

Open the AdFlow registration page, verify your email, and follow the prompts to enter your account and company details. Then sign in and open Websites and Placements.

## 2. Create a site and placement

1. In Websites and Placements, add the domain where you plan to install the tag.
2. Create a placement under the site and choose a format that fits the page. For Banner, also select the width and height.
3. Open the placement’s installation code. Record the site, placement ID, and target page, and get the shared script and placement code ready.

## How to tell you’re done

The placement belongs to the correct site, its format fits the location, and you have the code you need. Next, [install the AdFlow JS Tag directly](./adflow-sdk), then follow [Verify and launch](./verify-and-launch) to check your first ad.
