# Report data is missing or mismatched

First identify whether the issue is with requests, impressions, or reporting. Have the site, placement, and date range where you can reproduce the issue ready.

## 1. The report is empty

1. Check the account, site, placement, country filter, and date range, then rerun the report.
2. Check the report generation time to see whether it covers the period you’re investigating.
3. Follow [Verify and launch](./verify-and-launch) to check actual requests and impressions separately. If you see requests only, follow [Requests are sent but no ad appears](./no-ad-display).

## 2. The dashboard, breakdown table, or GAM shows different figures

1. Align dates, time zones, filters, and placement mappings.
2. Compare the same metric and confirm how it’s defined. For example, compare the request volume for one day on the chart with the same day in the Date breakdown.
3. If the difference remains, record both sources, the metrics and values in each, the date range, report generation times, and screenshots of the filters. Send these to your account manager.

To check monthly receivables or payment arrangements, see [Billing and monthly reconciliation](./billing).
