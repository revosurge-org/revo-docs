# Debugging tools

Choose a debugger for the ad format or integration you are testing. Have the placement ID, dimensions, or integration parameters ready, and use the fields shown in the tool.

<div class="adflow-table" role="region" aria-label="Debugging tools" tabindex="0">

| Tool | When to use it |
| --- | --- |
| [Banner Debugger](./banner-debugger) | Test banner dimensions and rendering. |
| [Pop Debugger](./pop-debugger) | Check how Pop ads trigger and how the page responds. |
| [Push Debugger](./push-debugger) | Test Push ads and check the browser environment. |
| [In-page Push Debugger](./inpage-push-debugger) | Check how notification-style ads render within the page. |
| [Native Debugger](./native-debugger) | Inspect Native ad content and rendering. |
| [S2S Debugger](./s2s-debugger) | Inspect server-side auction requests and responses. |

</div>

After testing, return to the live page and follow [Verify and launch](./verify-and-launch).
