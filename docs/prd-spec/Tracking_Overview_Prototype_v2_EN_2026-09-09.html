The 4 methods

🌐

Web Tracker Web

First-party JS on your landing page & advertiser site.

Fires conversion events (registration, deposit, FTD) as users move through your web funnel. Persists click_id in a first-party cookie (1-year expiry) — a user who lands, bounces, and returns 3 days later still attributes.

Best forWeb-only funnels, no server integration available
Skip ifYour funnel lives inside a mobile App
DeliveryJS snippet + GTM template (planned)
Effort~1 day · frontend only
Start with Web Tracker → See API reference
📱

AppsFlyer App MMP

Third-party mobile measurement partner. Industry standard.

RevoSurge integrates as a media source. AppsFlyer forwards install and in-app event postbacks to us. You configure androidAppsFlyerId / iOSAppsFlyerId on your landing page when initializing the web-tracker; we appear as a partner tile in your AppsFlyer dashboard. Play Store / App Store distribution uses Install Referrer (deterministic); APK / H5 wrapper falls back to probabilistic attribution with lower match rates.

Best forAny mobile App — Play Store, App Store, APK, or H5 wrapper
Skip ifYou don't have a mobile App at all (web-only funnel)
DeliveryConfigured on your landing page when initializing web-tracker · partner tile in AppsFlyer
Effort~2 hours · landing-page config
Start with AppsFlyer → Config health check
🔧

S2S Server Events S2S

Your back-office → our S2S API. Deepest control.

Server-to-server, fully programmatic. Pick one of two tiers based on what you want to measure — both share the same authentication and event contract, so upgrading later is drop-in.

S2S-Basic — reg + FTD only
Core acquisition metrics through the S2S channel. REST API subset (2 endpoints). More control than Partner Postback; no revenue / repeat-deposit tracking yet.
S2S-Full — complete iGaming event catalog
Everything in Basic plus repeat deposits, revenue events, cross-channel dedup, reconciliation. Contract: never-4xx · dedup fallback chain · 30-day acceptance window · is_claimable operator FTD claims.
Best forOwn back-office + engineering · Basic for acquisition, Full for LTV / dedup / revenue
Skip ifNo engineering capacity to integrate an HTTP API
DeliveryREST API (OpenAPI v3) · optional PHP / Node SDK · reconciliation file drop for Full
EffortBasic ~3-5 days · Full ~1-2 weeks · backend engineering
Start with S2S → See API reference
🔗

Partner Postback 🔥 Fastest start

Paste 2 URLs into your affiliate platform. Live today.

Your SaaS affiliate / back-office platform fires postbacks to us on registration and FTD. No code, no engineering, no waiting. Works out-of-the-box with Affilka, Cellxpert, Smartico, MyAffiliates, NetRefer, and other iGaming-friendly platforms.

Best forSaaS affiliate platform users · want same-day integration
Skip ifYou need cross-channel dedup with AppsFlyer, or arbitrary in-app events (upgrade to S2S)
Delivery2 postback URLs (reg + FTD) · self-serve slug + key
EffortSame day · no engineering
Start with Partner Postback → Platform macro map
⚠️
APK / H5-wrapped App distribution: Supported via probabilistic attribution — match rates are materially lower than Play Store / App Store (no Install Referrer). Weigh whether the reduced accuracy fits your CPA target.

FAQ

Which method is most accurate?
Web Tracker + S2S give the highest fidelity because they don't depend on third-party matching. AppsFlyer is industry-standard for App attribution. Partner Postback is only as good as your affiliate platform's macro coverage.
What if I send the same FTD through AppsFlyer and my back-office?
Both are stored. Your Integration Health Score surfaces conflicts. Cross-channel canonicalization policy is being finalized — until then, treat both signals as complementary and inspect divergences in the dashboard.
Do you accept postbacks in local currency (INR / MYR / USDT)?
Yes — we auto-convert using our published exchange rates. You don't need to convert to USD first.
Seconds vs milliseconds timestamps?
We normalize automatically, but you'll receive a loud integration warning if we detect ambiguity. Please stabilize on one format.
Is there a test mode / sandbox?
Yes. Test keys route to a visible event stream so you can self-validate without touching production. dryrun=1 on S2S and postback endpoints parses, validates, and echoes back exactly what we would record — without storing.
How do I know my integration is healthy?
Each product page shows an Integration Health Score — click_id coverage, event_id presence, identity coverage, median event age at receipt, suggested-field completeness — with a ranked remediation list and the CPA delta attached.
APK / H5-wrapper Apps — is that supported?
Yes, supported via probabilistic attribution. Match rates are materially lower than Play Store / App Store (no Install Referrer). Factor the reduced accuracy into your CPA target.
